# SonicJS 财税 SEO Production Edition

基于 SonicJS、Cloudflare Workers 与 D1 的生产级内容管理与 SEO 获客方案。

本分支用于构建企业级内容系统与长期 SEO 运营基础设施。

---

## 项目定位

SonicJS 财税 SEO Production Edition 面向：

- 企业官网
- 财税服务平台
- 内容营销站点
- 需要持续搜索流量增长的网站

核心目标：

- 稳定运行在 Cloudflare Edge 环境
- 使用 D1 管理业务数据和内容数据
- 支持后台内容运营
- 支持大规模 SEO 页面扩展
- 保持 main 分支生产稳定

---

## 技术架构

### Cloudflare 平台

支持：

- Cloudflare Workers
- Cloudflare D1 Database
- Cloudflare R2 Storage
- 自定义域名
- Secrets 环境变量管理

生产原则：

- 域名由部署者自行绑定
- 管理员账号首次部署创建
- 敏感信息不提交 Git
- 测试功能经过 PR 审核后进入生产

---

## 财税 SEO 内容系统

支持建立长期搜索入口：

- 城市 + 服务关键词页面
- 行业解决方案页面
- 企业问答页面
- 财税知识文章
- 产品服务页面
- 自动 Sitemap
- 内部链接体系

推荐内容流程：

来源信息
→ 原创整理
→ 企业实际价值解读
→ SEO 页面发布
→ 数据分析优化

## 开发流程

所有修改必须遵循：

1. 创建独立开发分支
2. 完成功能开发
3. 检查 Git diff
4. 创建 Pull Request
5. Review 后合并 main

禁止：

- 未测试代码进入 main
- 半成品功能直接上线
- 提交密钥和账号信息

---

## 部署检查清单

上线前确认：

- 数据库迁移完成
- 环境变量配置完成
- 后台可以登录
- 页面访问正常
- Sitemap 正常生成
- SEO 页面可索引
